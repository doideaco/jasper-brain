# Usage rules

**First-time setup:** upload the SVG via `/brands/jasper/assets`, then edit this item and use the **Browse** button on the Asset row to pick the file. The SVG should be uploaded once as `brainy-on-light.svg` (and optionally a recoloured `brainy-on-dark.svg` for use over Ink backgrounds).

**Do**
- Use the SVG wherever possible. PNG only as a fallback.
- Render alongside the parent Jasper wordmark when the surface needs to communicate "this is a Brain product, made by Jasper" — e.g. the public Brand kit page footer, the admin top nav.
- Keep the colour as supplied (near-black `#292b2b`). The mark is intentionally neutral so it doesn't compete with the Jasper Brand red.

**Don't**
- Don't recolour the wordmark to Brand red. Brainy is a sub-product mark; Jasper red is the parent-brand accent. Mixing the two muddies the hierarchy.
- Don't apply effects — drop shadows, gradients, outlines, glows.
- Don't separate the icon from the wordmark. They are one mark.
- Don't stretch or squash. Always scale uniformly.
- Don't use Brainy as a replacement for the primary Jasper logo on Jasper-brand surfaces (jasper.ai marketing, Jasper product UI). Brainy is for Brain-product surfaces only.
